# 🤖 Assistente WhatsApp com Python

Automação pessoal conectada ao WhatsApp usando Python, Flask e Baileys. Esse projeto permite controlar seu computador via mensagens no WhatsApp (abrir apps, criar lembretes, etc.).

## 💡 Objetivo

Criar um chatbot local com comandos personalizados para uso pessoal e futuramente adaptável para empresas.

## 🚀 Tecnologias

- Python 3.10+
- Flask
- Node.js + Baileys
